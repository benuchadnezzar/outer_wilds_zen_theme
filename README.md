# Outer Wilds Zen Theme

A custom Zen Browser theme overlay inspired by _Outer Wilds_.

The goal is not to recreate the game UI literally, but to make Zen feel like it belongs in the same world: deep-space surfaces, warm Hearthian instrument lighting, parchment-like text, and restrained Nomai-inspired accents.

## Design Approach

This mod is intended to sit on top of an existing Zen setup, rather than replacing it.

Recommended stack:

- **Neo-Zen** — layout, structure, and browser UI behavior
- **Transparent Zen** — transparency, glass, and background imagery
- **Outer Wilds Zen Theme** — palette, active states, text treatment, borders, and thematic accents

The three mods should have clearly separated responsibilities so they can be updated or disabled independently.
